# docs

`figure_png_baseline.json` lands here when you run `check-figure-parity --snapshot`: the
recorded dimensions of every saved figure, so a later regeneration cannot quietly resize
one. Commit it — the point is that a change of size shows up as a reviewable diff.

Anything else you keep about the figures belongs here too. A living inventory of which
figures exist, which are placed in the prose and which are still pending, is worth more
than it looks once there are more than a dozen.
